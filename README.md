# 线束钉板放样与装配推演台

面向小批量线束工坊的离线工具：在钉板画布上放样走线、核对裁线、推演装配顺序。
纯本地运行，无需联网与第三方依赖——后端只用 Python 标准库（`http.server` + `sqlite3`），
前端为原生 HTML / CSS / JavaScript / SVG（ES Modules，无构建步骤）。

## 启动

```bash
python3 server.py            # 默认 127.0.0.1:8765
python3 server.py --port 9000
```

浏览器打开 <http://127.0.0.1:8765/> 即可。存档保存在同目录 `harness.db`（SQLite）。

## 功能一览

- **钉板画布**：可缩放（滚轮）/平移（空白拖拽或中键），网格吸附。放置连接器（J）、
  分支点（B）、固定钉（N）、**实体拼接件（S：闭端帽 / 对接管 / 超声焊）**、禁布区（Z，拖出矩形）。
- **实体拼接点**：拼接件带孔位容量、适用线径、剥线长度与保护套（热缩管/焊壳）外径×长度；
  布线时可把导线端接到指定孔位（也可选中导线后**拖动端头**到连接器/拼接件重接）。
- **布线**（W）：点连接器/拼接件选起点孔位 → 点击途经点（自动吸附钉/分支/拼接点并绑定）→
  点目标选终点孔位。导线带线号、线径、颜色；折线路径可拖动顶点、双击加点、右键删点。
  **重合路径自动拆分汇成线束段**（含部分重合的共线段），移动节点或拼接点后，支路裁线长度、
  共束段、网络连通关系同步重算。
- **多分支接线网络**：接线表每行 `网络名 端子1 端子2 [端子3…]`，**同一网络名可描述多个
  连接器端子**（也可同名分多行）。系统沿导线与拼接件用并查集追踪连通，自动标出：
  **悬空端**（导线悬空 / 拼接件只接 0–1 根）、**跨网合并**（异名端子被物理导通）、
  **端口超容/孔位重复**、**线径组合不适配**（超出适用线径；闭端帽粗细比 >1.6）、
  **导线两端落入同网**（不经本线已连通的冗余回路）、**拼接位置侵入禁布区**、
  对接件缺保护套、网络未连通等。
- **自动核算**：按线径估算束径 `D = k·√(Σdᵢ²)`；标出弯曲半径不足（切线长约束
  `tᵢ+tᵢ₊₁ ≤ L`）、穿越禁布区、端子重复占用、支路余量不足、维修余量不足、线号重复。
- **端头工艺**：每端可设剥线长度、压接端子型号、维修余量；导线落到拼接件时剥线长度默认
  取拼接件设置（改拼接件剥线会同步其各导线端）。裁线长 = 路径长 + 维修余量 + 剥线，并按设定向上取整。
- **展开输出**：逐根裁线表（可下 CSV，**含拼接孔位与保护套尺寸、拼接件工艺表**）、
  按线径/颜色的用料汇总、分支绑扎位置（画布橙色 × 标注）、打印模板附**拼接件下料与压接工艺表**、
  主干优先的装配顺序。
- **装配模式**：先逐根送线确认，再按拼接件逐件引导 **集线确认 → 压接/焊接确认 → 套管确认**，
  拼接件未接齐或存在校验错误时“完成拼接”不可用，未接齐不得完成整个推演。
- **编辑与备份**：撤销/重做（Ctrl+Z / Ctrl+Y）、JSON 导出导入（**保留拼接拓扑**；v1 旧方案
  无需手工迁移即可打开）、本地库存档（SQLite）。
- **打印**：按实际尺寸分页的 A4 SVG 钉板模板（100% 比例打印即 1:1，含拼接重叠与
  角规线，绘制拼接件与孔位）与线号标签页。

## 快捷键

`V/J/B/N/S/Z/W` 切换工具（S=拼接件，顶栏可选闭端/对接/超声焊类型），`Delete` 删除选中，
`Esc` 取消/清选，`Backspace` 布线中撤点，方向键微调选中节点（Shift ×10），`Ctrl+Z / Ctrl+Y` 撤销重做。

## 接线表

“数据”页可维护接线表：每行 `网络名 端子1 端子2 [端子3 …]`，端点写作 `J1.3`；
同一网络名出现在多行即合并为多分支网络（旧格式 `线号 起点 终点` 仍可读）。
“从布线生成”按导线与拼接件追踪物理连通分量自动填充；校验时标出悬空端、跨网合并、
端口超容、线径组合不适配、导线两端落入同网（冗余回路）、拼接件侵入禁布区等。

## 电气检验批次（/inspect）

从已保存的钉板方案创建检验批次：按**新拓扑冻结网络快照**——沿导线与实体拼接件用并查集
追踪连通（拼接件各孔内部导通，多根导线汇成多端网络），快照同时保留拼接件的类型、容量、
适用线径、剥线与保护套尺寸。批次经历
**待准备 → 检测中 → 待复核 → 已归档** 四种状态（顶栏「⚡ 电气检验批次」进入）。
此后再移动/删除拼接点或改线，不会影响已创建批次的冻结快照。

- **推荐测点**：开测后按尚未覆盖的网络推荐探针组合；连接器正视图以红/蓝标亮
  当前探针 A/B、绿色脉冲标亮下一测点，点击针位即可选定探针；支持扫描/速录
  两个端点（如 `J1.1 J2.1` 回车）。录入导通结果、阻值（含单位）与极性。
- **CSV 导入**：先预览端点匹配、与既有读数及文件内部互相冲突的记录，确认后
  导入；无法解析的行自动跳过。
- **拓扑分析**：自动找出开路、跨网短接、错接与重复测量；端点无效、单位缺失、
  同一对端点结论矛盾时交人工处理，不改放样方案。
- **操作**：可暂停后续测、撤回最近读数、按网络重测（撤回该网络读数）。
- **归档**：异常均有处置结论后才能归档；归档批次可按同一方案并排比较，
  并打印包含针位、实测值与处置记录的复核单。

## 首件尺寸检验批次（/fai）

从已保存的钉板方案创建首件批次：**冻结连接器姿态、分支点、拼接件（含类型/孔位/剥线/保护套）、
包覆边界与理论尺寸**（顶栏「📏 首件尺寸检验」进入）。批次经历
**待准备 → 测量中 → 待复核 → 已放行** 四种状态。冻结后方案再变不影响批次内容，
只在列表与详情上**标记快照过期**（连接器/分支/拼接位置或拼接件工艺参数改变、改线、改包覆边界都会触发；
仅追加自选测点不会；另建新批次即可，旧记录不改写）。

- **检验路线测点（按顺序引导）**：连接器中心距、分支点沿支路到相邻基准的定位尺寸、
  支路折线长度、包覆起止边界、连接器到首个自由折点的尾部余量。**直通导线不造尾部余量**；
  导线保存端点与实际路径不一致时，测点名称/基准/理论值一律以**路径实际绑定节点**为准。
- **SVG 钉板引导**：在冻结快照钉板图上高亮当前测点的基准与测线，点路线或图上测线即定位；
  也可**点选两个基准**直接定位测点录入。待准备阶段可点两基准补录**自选测点**（自定义公差），
  自选测点不影响几何指纹，不会误报快照过期。
- **测量录入**：按理论值与上/下公差自动算偏差并判定合格/超差；单位 mm/cm/m 只换算一次，
  **空单位按 mm 计但原样保留为“单位缺失”异常**（刷新/打印后仍在，提示补注、不阻塞放行）；
  无法识别的单位标**单位不明**（读数存为待人工、阻塞放行）。系统还标出**基准缺失、测点错序、
  结论矛盾、重复测量**。
- **处置与返工**：超差/无效读数须登记 **返工 / 让步接收 / 报废**。登记返工后**必须新增合格读数**
  才能放行（仅登记返工、未重测会被拒绝）；让步/报废为授权结案。
- **操作**：支持**中断续测**（任意时刻关闭后回到批次继续，自动定位下一待测项）、
  **撤回最近读数**（也可在读数表撤回指定一条）。
- **放行与保护**：必测项全部合格、或全部完成授权处置且无未决返工方可**放行**；
  **已放行记录只读、不可改写、不可删除、不可撤回**。
- **比较与打印**：同方案的已放行批次可**并排比较**各测点实测与偏差；打印
  **首件检验单**（测点、基准、理论值、公差、实测值、偏差、判定、处置与签字栏）。
