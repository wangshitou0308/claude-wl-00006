# 线束钉板放样与装配推演台

面向小批量线束工坊的离线工具：在钉板画布上放样走线、核对裁线、推演装配顺序。
纯本地运行，无需联网与第三方依赖——后端只用 Python 标准库（`http.server` + `sqlite3`），
前端为原生 HTML / CSS / JavaScript / SVG（ES Modules，无构建步骤）。

## 启动

```bash
python3 server.py            # 默认 127.0.0.1:8765
python3 server.py --port 9000
```

浏览器打开 <http://127.0.0.1:8765/> 即可。存档保存在同目录 `harness.db`（SQLite）。

## 功能一览

- **钉板画布**：可缩放（滚轮）/平移（空白拖拽或中键），网格吸附。放置连接器（J）、
  分支点（B）、固定钉（N）、禁布区（Z，拖出矩形）。
- **布线**（W）：点连接器选起点端子 → 点击途经点（自动吸附钉/分支点并绑定）→
  点目标连接器选终点端子。导线带线号、线径、颜色；折线路径可拖动顶点、双击加点、
  右键删点。**重合路径自动拆分汇成线束段**（含部分重合的共线段），移动节点后
  支路长度与用料同步更新。
- **自动核算**：按线径估算束径 `D = k·√(Σdᵢ²)`；标出弯曲半径不足（切线长约束
  `tᵢ+tᵢ₊₁ ≤ L`）、穿越禁布区、端子重复占用、支路余量不足、维修余量不足、
  线号接错端点（对照接线表）、线号重复。
- **端头工艺**：每端可设剥线长度、压接端子型号、维修余量；裁线长 =
  路径长 + 维修余量 + 剥线，并按设定向上取整。
- **展开输出**：逐根裁线表（可下 CSV）、按线径/颜色的用料汇总、分支绑扎位置
  （画布橙色 × 标注）、主干优先的装配顺序。
- **逐步推演**：按装配顺序逐根高亮当前导线及其途经的钉位，确认后才推进；
  可勾选“确认后锁定”。锁定的路线不参与“重排未锁定路径”。
- **编辑与备份**：撤销/重做（Ctrl+Z / Ctrl+Y）、JSON 导出导入、本地库存档（SQLite）。
- **打印**：按实际尺寸分页的 A4 SVG 钉板模板（100% 比例打印即 1:1，含拼接重叠与
  角规线）与线号标签页。

## 快捷键

`V/J/B/N/Z/W` 切换工具，`Delete` 删除选中，`Esc` 取消/清选，`Backspace` 布线中撤点，
方向键微调选中节点（Shift ×10），`Ctrl+Z / Ctrl+Y` 撤销重做。

## 接线表

“数据”页可维护接线表（每行 `线号 起点 终点`，端点写作 `J1.3`），或用
“从布线生成”自动填充；校验时逐根比对实际起讫端子，不一致即报“线号接错端点”。
